# Legacy compiler pragmas

Every file listed below declared an exact `pragma solidity 0.8.15` (or `=0.8.15`) until commit `623777ebbdaf3ae66c32cc964efcc373fe04a6a1` relaxed it to `>=0.8.15` and pinned the whole project to one compiler through `solc_version` in `foundry.toml`.

The list is a historical record. Contracts deployed before that commit were built with 0.8.15, and their on-chain bytecode is no longer reproducible from the current sources, so this file is what ties a deployment to the compiler it was verified with. Nothing reads the list at build time and it is not expected to grow: new code uses the pinned compiler.
